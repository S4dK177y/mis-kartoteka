## 📖 О проекте

**МИС Картотека** — это прототип веб-приложения для автоматизации работы медицинского персонала. Система позволяет вести учет поступивших пациентов, отслеживать переводы между отделениями, сохранять историю консультаций и заключения Военно-врачебной комиссии (ВВК).

### ✨ Ключевые возможности
- **Управление пациентами:** Полный цикл работы с профилем пациента (поступление, перевод, выписка), включая учет специфичных военных данных (звание, статус, номер части).
- **История болезней и ВВК:** Ведение медицинских записей и документации профильных специалистов.
- **Хранение документов:** Безопасная загрузка и предпросмотр сканов документов, привязанных к истории болезни.
- **Криптография:** Высокочувствительные персональные данные шифруются на уровне приложения (Application-Level Encryption) по алгоритму **ГОСТ Р 34.12-2018 "Кузнечик"** в режиме MGM до попадания в базу данных.
- **Отчетность:** Автоматическая генерация сводных таблиц в формате Excel.
- **Администрирование:** Разделение ролей (Врач / Администратор), управление пользователями, безопасный сброс паролей и ведение полного Audit Log'а действий в системе.

## 🛠 Технологический стек

- **Frontend:** React, Vite, Custom CSS (CSS Variables), Lucide Icons
- **Backend:** Node.js, Express.js, Prisma ORM
- **Database:** PostgreSQL (ранее SQLite)
- **DevOps / Infra:** Docker, Docker Compose, Nginx

## 🐳 Самостоятельное развертывание (Docker)

Запуск собственного инстанса проекта осуществляется через Docker Compose:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/S4dK177y/mis-kartoteka.git
   cd mis-kartoteka
   ```
2. Создайте файл переменных окружения `.env` (например, через `nano`) и пропишите туда доступы к базе данных.
3. Запустите контейнеры:
   ```bash
   docker compose up -d --build
   ```
4. Откройте браузер и перейдите по адресу `http://localhost`. При первом запуске система автоматически создаст базу данных и предложит создать администратора.
